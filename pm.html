  • 时间：2026 年下半年深度报道（搜狐 / 第三方研报）
  • 人物/机构：国内制造企业；SaaS 供应链软件厂商
  • 事件：第三方研报数据显示，2026 年国内制造企业数字化软件预算增速放缓至 5% 左右，但对 IT 投资回报率（ROI）的要求空前严苛。过去"买一套系统必须打包全套模块"的"全家桶"采购模式正在被淘汰——企业开始倾向于：主系统（ERP）用传统大厂，但 SCM、WMS、SRM 等模块选择专注的垂直 SaaS 厂商进行"模块化拼装"。典型组合：用友 U9 + 积加 SRM + 某 WMS + 某 TMS

💡 看点：这个趋势对 ERP 厂商的产品策略影响很大——如果你是大厂 ERP，可能要考虑开放更多 API 让垂直 SaaS 对接；如果你是垂直厂商，反而应该坚持"小而精"的定位，在某个模块上做到最好、集成做到最顺。对 ERP 产品经理来说，你的接口设计（尤其是采购/供应链模块对外暴露的 API）可能比你模块内部的功能迭代更能影响客户决策
